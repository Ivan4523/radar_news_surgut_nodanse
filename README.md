# 📡 Новостной радар Сургута и Югры

Прототип для хакатона СИА-ПРЕСС. Система сама проверяет источники (по умолчанию каждые 15 минут),
находит новые сообщения, отбирает значимые для Сургута и Югры и присылает редактору в Telegram:
заголовок, краткую суть, источник, ссылку и время.

**Сургут — приоритет № 1, далее вся Югра.**

## Как это работает

```
 Сбор                    Отбор                              Уведомление
 RSS, сайты, Telegram -> география + тема + шум + дубли ->  Telegram-бот, окно, веб-дашборд
 (11+ источников)        оценка важности 0..100             + история находок (SQLite)
```

1. **Сбор.** Источники описаны в `config.yaml`: `rss`, `html` (CSS-селектор) и `telegram`
   (публичный веб-просмотр канала `t.me/s/...`). Опрашиваются параллельно, сбой одного не мешает остальным.
2. **Отбор.**
   - *География:* вес по слову (Сургут 40, Югра 25, другие города округа меньше). Если в тексте города нет,
     берётся 60 % веса от `geo_hint` источника. Если при этом назван чужой регион
     («в Саратовской области», «в Москве»), подсказка отключается и балл снижается.
   - *Темы:* ЧС, правопорядок, власть, экономика, транспорт, ЖКХ, общество: ключевые слова с весами.
   - *Шум:* афиши, дайджесты, поздравления, реклама дают штраф.
   - *Дубли:* заголовки сравниваются по схожести символов и основ слов (`dup_threshold`).
     Разные числа или названия (улица Энгельса / улица Мира, 20 / 27 ноября) и малое пересечение
     содержательных слов делают заголовки разными новостями, а не дублями.
     Та же новость из другого источника не дублируется, а повышает «подтверждённость».
   - *Достоверность:* у каждого источника `trust` 1..5 (власть и проверенные СМИ выше, «народные» каналы ниже)
     и пометка 🟢/🟡/🔴 в уведомлении.
3. **Уведомление.** Находки с баллом не ниже `notify_min_score` уходят в Telegram с пояснением
   «почему такой балл». Все находки сохраняются в историю и видны в окне и на дашборде.
   - *Краткая суть:* из текста источника выбираются 1-2 самых содержательных предложения
     (слова тем, география, цифры, позиция), без ссылок, хэштегов, эмодзи и рекламных хвостов.
     Это выжимка по правилам, без нейросети: ничего не придумывает, только цитирует источник.
4. **Обратная связь.** Под каждой новостью кнопки 👍 «Важно» и 👎 «Не то». Отзывы сохраняются, и радар
   подстраивает баллы: источники и темы с 👎 теряют до 8 баллов, с 👍 получают (после 3 отзывов).
   Команда `/quality` показывает точность по оценкам редактора. Выключить обучение: `feedback_weight: 0`.

### Формула балла

```
балл = география + тема + приоритет источника × 3 + (доверие − 3) × trust_weight
       + свежесть (+10 до 2 ч, +5 до 6 ч) − шум − штраф за чужой регион
```
Бонусы источника (приоритет, доверие, география «по источнику») умножаются на `min(1, тема / topic_full)`:
без сильной темы одной «официальности» источника для порога не хватает.
Потолки: без привязки к региону не выше 20, без значимой темы не выше `no_topic_cap`.
Шкала 0..100: 🔥 от 60, ❗ от 45, ℹ️ от `notify_min_score` (по умолчанию 35).

## Быстрый старт

```bash
pip install -r requirements.txt
cp .env.example .env        # впишите токен бота и свой chat_id
python radar_gui.py         # окно (Qt)
# или без окна: python news_radar.py   (меню в консоли)
```

На Windows можно запустить `start_radar.bat`, остановить `stop_radar.bat`.

### Как получить токен и chat_id

1. В Telegram откройте **@BotFather**, команда `/newbot`, скопируйте токен.
2. Напишите своему боту `/start`. Он ответит, что бот закрытый, и покажет ваш ID.
3. Впишите токен и ID в `.env`. Нескольких получателей можно через запятую: `TELEGRAM_CHAT_ID=111,222`.
4. В окне на странице «Журнал» нажмите «Тест Telegram».

> `.env` содержит секреты: не отправляйте его и не публикуйте в репозитории (он уже в `.gitignore`).
> Если токен попал в чужие руки, перевыпустите его: BotFather → `/revoke`.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | коротко: что умеет бот |
| `/top` | топ находок за сутки (`/top 10`) |
| `/history` | история по убыванию баллов |
| `/latest` | самые свежие находки |
| `/sources` | источники, доверие, состояние |
| `/quality` | качество по оценкам редактора 👍/👎 |
| `/status` | последняя проверка и счётчики |
| `/demo` | тестовое уведомление |

Те же действия доступны кнопками под полем ввода.

## Настройка (`config.yaml`)

- `interval_minutes`, `notify_min_score`, `max_alerts_per_cycle`: частота и порог уведомлений.
- `geo_weights`, `categories`, `noise_words`: веса слов (поиск с начала слова: `пожар` найдёт `пожарные`).
- `foreign_places`, `foreign_penalty`: чужие регионы.
- `feedback_weight`, `feedback_min_votes`: насколько сильно отзывы 👍/👎 меняют баллы.
- `sources`: добавьте источник по образцу. Для Telegram достаточно `"@ник_канала"`.
  Свой Telegram-канал, RSS или сайт подключаются без правки кода.
- `baseline_on_first_run: true`: первый заход в новый источник только запоминает записи и не шлёт старые новости.
  Для демонстрации поставьте `false`.

После правки `config.yaml` перезапустите программу.

## Проверка качества

```bash
python eval_radar.py                      # по размеченной выборке labeled_sample.csv
python eval_radar.py --live               # по отметкам 👍/👎 из Telegram
python eval_radar.py --export my.csv      # выгрузить находки для своей разметки (колонка label: 1/0)
python eval_radar.py --csv my.csv         # оценить по своей разметке
```

Скрипт заново оценивает новости текущими настройками и считает точность (какая доля присланного
нужна), полноту (какую долю нужного поймали) и F1, сравнивает с вариантом «присылать всё подряд»,
показывает, как меняются метрики при другом пороге, и перечисляет ошибки.

`labeled_sample.csv`: 149 находок из истории радара; разметку (1 = стоило сообщить редактору)
сделал автор прототипа, не редакция. Для честной оценки её должен проверить редактор.
Веса в `config.yaml` под эту выборку не подбирались.

## Ограничения прототипа

- Веса слов подобраны вручную. На выборке из 149 новостей радар даёт точность около 61 % и полноту около 93 %
  (F1 0,74, прислано 41 из 149; до доработки было 48 % / 93 % / 0,63 / 52). Это измерено на той же выборке,
  на которой слегка подправлялись шумовые слова и темы, поэтому цифры оптимистичны: для честной оценки нужна
  разметка редактора на новых данных. Шум в основном остаётся от официальных страниц.
- Нет ВКонтакте и закрытых каналов (у них нет публичного веб-просмотра).
- Сайт `admhmao.ru` отвечает ошибкой 447, поэтому правительство Югры читается через Telegram.
- «Краткая суть» это выбор предложений из текста источника, а не пересказ нейросетью.
- Обучение на отзывах работает по источнику и теме целиком: оно не понимает, почему именно новость не понравилась.
- Все даты хранятся в UTC, показываются по времени Сургута (UTC+5).
